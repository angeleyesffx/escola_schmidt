# Cards da Home - Guia de Arte

Substitua estes arquivos pelas ilustracoes finais (mantendo os mesmos nomes):

- card-calendario.png
- card-chamada.png
- card-alunos.png
- card-desempenho.png
- card-eventos.png
- card-perfil.png

Especificacao recomendada:

- Formato: PNG ou SVG exportado para PNG
- Tamanho: 1200x900
- Fundo: transparente
- Estilo: flat + outline fino, cantos suaves, paleta turquesa/azul gelo

Prompt base para geracao:

"Ilustracao flat, clean e amigavel no tema patinacao artistica para app mobile escolar. Paleta turquesa, azul gelo, lilas pastel e pessego suave, com contornos finos e fundo transparente. Composicao horizontal para card de interface." 

Variacoes por card:

1. Calendario: agenda mensal, marca de eventos e patim no canto.
2. Chamada: prancheta com checklist de presenca.
3. Alunos: grupo de 3 patinadores em niveis diferentes.
4. Desempenho: grafico de evolucao com medalha.
5. Eventos: calendario com destaque e elementos de competicao.
6. Perfil: avatar com selo de progresso.
